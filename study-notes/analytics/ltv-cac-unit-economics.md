## Intuitive Mental Model
Customer Lifetime Value (LTV) is the total gross profit generated by a customer over their entire relationship. Customer Acquisition Cost (CAC) is total sales/marketing spend divided by new customers acquired. The golden benchmark is LTV:CAC >= 3:1 with a CAC Payback Period under 12 months.

---

## The Interview Trap & Senior Insight
Candidates calculate LTV using top-line revenue instead of gross margin! If revenue per user is $100/mo but cloud server costs are $80/mo, your gross margin is only 20%. LTV = (ARPU * Gross Margin %) / Churn Rate.

---

## Technical Implementation
```python
def calculate_ltv(arpu_monthly, gross_margin_pct, monthly_churn_rate):
    # LTV = Lifetime Margin = (Monthly Revenue * Gross Margin) / Churn Rate
    if monthly_churn_rate <= 0: return float('inf')
    return (arpu_monthly * gross_margin_pct) / monthly_churn_rate

ltv = calculate_ltv(arpu_monthly=50.0, gross_margin_pct=0.75, monthly_churn_rate=0.03)
cac = 350.0
print(f"LTV: ${ltv:.2f}, LTV:CAC Ratio: {ltv / cac:.2f}x") # LTV: $1,250.00, Ratio: 3.57x
```
