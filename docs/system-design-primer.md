# Machine Learning System Design Primer

Step-by-step framework for answering ML system design questions.

1. **Clarify Requirements**: Functional requirements, throughput (QPS), latency budget, freshness constraints.
2. **Frame as ML Task**: Objective function, label definition, feature sources.
3. **Data Pipeline**: Batch vs streaming ingestion, feature store, training data generation.
4. **Model Architecture**: Candidate retrieval vs ranking, inference latency optimization.
5. **Evaluation & Serving**: Offline benchmarking vs online A/B testing, fallback heuristics.
