# Deep Learning Foundations Guide

Core concepts in modern neural network training and stability.

* **Weight Initialization**: He (Kaiming) for ReLU activations; Xavier (Glorot) for Sigmoid/Tanh.
* **Normalization**: Batch Normalization across batches; Layer Normalization across features per sample (crucial for Transformers).
* **Learning Rate Schedules**: Cosine annealing with warm restarts, linear warmup.
