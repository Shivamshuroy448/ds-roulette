# End-to-End A/B Testing Framework

Comprehensive playbook for designing, launching, and analyzing digital controlled experiments.

1. **Hypothesis Formulation**: Clear cause-and-effect statement tied to primary metrics.
2. **Randomization Unit**: User-level, session-level, or cluster-level assignment.
3. **Power Analysis**: Calculate sample size and runtime before starting test.
4. **Sanity Checks**: Sample Ratio Mismatch (SRM) test using Chi-Square distribution.
5. **Decision Rule**: Pre-specified alpha (0.05) and two-sided p-value threshold.
