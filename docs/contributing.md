# Contributing to DS Roulette

Guidelines for expanding curriculum topics, adding drills, and enhancing UI components.

## Adding a Topic
1. Open `src/data/topics.js`.
2. Append a new topic object conforming to the standard schema with title, category, difficulty, intuition, code snippet, and 7-8 quiz drills.
3. Run verification scripts via `node scripts/verify-topics.js`.
