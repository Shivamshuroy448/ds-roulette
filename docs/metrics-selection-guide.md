# Metric Selection Guide for Machine Learning

Guidelines for choosing evaluation metrics based on problem constraints and class distributions.

* **Balanced Classification**: Accuracy, ROC-AUC, Log-Loss.
* **Imbalanced Classification**: Precision, Recall, F1-Score, Precision-Recall AUC (PR-AUC).
* **Regression**: RMSE (penalizes large errors), MAE (robust to outliers), MAPE (scale-invariant percentage error).
